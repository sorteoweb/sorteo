Cómo funciona

Un flujo simple para el comprador y organizado para el administrador. Este demo presenta el concepto antes de conectar Stripe real.

1

Elige un arte

El cliente selecciona una pieza digital disponible en la galería. Cada compra puede incluir una o varias participaciones.

2

Paga con Stripe

El sistema redirige al comprador a Stripe Checkout para completar el pago de forma segura.

3

Recibe su código

Después del pago, el comprador recibe confirmación, su arte digital y su código de participación.

Términos del demo

Pagos
